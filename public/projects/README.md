Drop real project images here, named to match the `image` path in
`data/projects.json` (e.g. `horta-urbana.jpg`). Until an image exists at
that path, the project card shows a teal-to-ink gradient placeholder
instead — nothing breaks if this folder stays empty during development.

Recommended: 16:10 landscape photos, at least 900px wide, under ~400KB each.
